# ras.ruchi

A portfolio site for Shruchi Jaiswal, textile designer. It is built as a shade card: her Yellow Dwelling collections appear as cut swatches in every colourway, and her Behance studies appear in her own words.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000. For a production build:

```bash
npm run build
npm start
```

## Hosting on GitHub Pages

`npm run github` fills the `github-repo` folder with exactly the files the GitHub repository needs, including a workflow that builds and publishes the site on every push. See `GITHUB_HOSTING.md` for the step-by-step setup and for publishing new versions.

## Refreshing the images

All photographs are stored in `public/images` as optimised WebP files, and the text and image data they come with live in `src/data/*.json`. Both are generated by:

```bash
node scripts/fetch-images.mjs          # everything
node scripts/fetch-images.mjs tyd      # The Yellow Dwelling collections only
node scripts/fetch-images.mjs behance  # Behance studies only
```

The Yellow Dwelling catalogue snapshot it reads is in `scripts/data/` (taken from the shop's public product feed). Behance pages block scripted downloads, so `scripts/data/behance-raw.json` was captured in a browser; only the images are fetched by the script.
